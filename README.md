# Vertex Dungeon — GitHub Pages Support Site

This folder is ready to publish with GitHub Pages.

## Files

- `index.html` — public landing/support page
- `support.html` — support, purchases, restoration, refunds
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `style.css` — site styling
- `STORE_SUBMISSION_CHECKLIST.md` — Google Play / Apple disclosure notes

## Publish with GitHub Pages

1. Create a **public** GitHub repository, for example `vertex-dungeon-support`.
2. Upload all files in this folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save.

If your GitHub username were `USERNAME`, the URLs would normally be:

- Support: `https://USERNAME.github.io/vertex-dungeon-support/support.html`
- Privacy: `https://USERNAME.github.io/vertex-dungeon-support/privacy.html`
- Terms: `https://USERNAME.github.io/vertex-dungeon-support/terms.html`

Use your actual GitHub Pages URLs in the store forms and inside the app.

## Recommended in-app links

Add a reachable area such as:

**Settings / About → Legal**
- Privacy Policy
- Terms of Service
- Support

Opening these links in the user's normal browser is fine.

## Important

The Privacy Policy correctly says that **CD Industries does not directly collect personal information**, while disclosing that the Google Mobile Ads SDK used by AdMob processes data for advertising and related purposes.

Do not mark the app as collecting "no data" in store privacy forms solely because CD Industries itself has no backend. Third-party SDK behavior must also be disclosed.
